## 2026-09-07 - Copy Link Feedback & Clipboard Error Handling
**Learning:** Adding a "Copy Link" action button to utility pages enhances sharing UX. When using `navigator.clipboard.writeText()`, both `.then()` and `.catch()` handlers must be implemented to provide accurate visual feedback ("Copied!" vs "Failed") and announce the exact state via an `aria-live` polite region to avoid misleading screen reader users on permission errors.
**Action:** Always complement clipboard API calls with success/error text transitions and `aria-live` announcements to ensure transparent status feedback for all users.
