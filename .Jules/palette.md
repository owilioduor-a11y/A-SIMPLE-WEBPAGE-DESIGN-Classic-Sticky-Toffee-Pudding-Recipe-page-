## 2024-05-13 - [Accessibility: Mobile Navigation and Keyboard Focus]
**Learning:** Converting non-semantic interactive elements (like `div` toggles) to semantic `<button>` elements with ARIA attributes (`aria-expanded`, `aria-controls`) significantly improves screen reader accessibility without changing the visual design.
**Action:** Always prefer semantic HTML elements for interactions and use `:focus-visible` to provide clear, high-contrast focus indicators that match the site's aesthetic.
