## 2024-05-15 - Mobile Navigation Accessibility
**Learning:** Using a `button` instead of a `div` for the mobile menu toggle is essential for keyboard and screen reader accessibility. Adding `aria-expanded` and `aria-controls` provides critical state information to assistive technologies.
**Action:** Always use semantic buttons for interactive toggles and synchronize ARIA states with visual state changes.

## 2024-05-15 - Global Focus Indicators
**Learning:** Luxury aesthetic projects often lack clear focus indicators. Using `:focus-visible` with an offset gold outline maintains the luxury feel while ensuring high visibility for keyboard users.
**Action:** Implement brand-consistent focus indicators site-wide using `:focus-visible` to avoid affecting mouse users while aiding keyboard navigation.
