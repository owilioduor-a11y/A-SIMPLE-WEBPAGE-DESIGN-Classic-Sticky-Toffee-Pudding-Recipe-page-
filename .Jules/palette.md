# Palette's Journal - Classic Dinner Resort

## 2025-05-14 - Mobile Navigation Accessibility
**Learning:** In luxury-themed static sites, interactive elements are often implemented as divs for styling ease, sacrificing keyboard and screen reader accessibility. Using semantic <button> and ARIA attributes (aria-expanded, aria-controls) is crucial for an inclusive premium experience.
**Action:** Always verify that mobile toggles are semantic buttons and manage their expanded state with ARIA attributes.
