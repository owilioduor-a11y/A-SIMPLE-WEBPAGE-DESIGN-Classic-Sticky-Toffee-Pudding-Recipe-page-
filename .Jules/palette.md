# Palette's UX Journal

## 2025-05-14 - Accessible Mobile Navigation
**Learning:** Using `div` elements for interactive components like mobile menu toggles creates barriers for screen reader users and keyboard navigation. Semantic `<button>` elements with appropriate ARIA attributes (`aria-expanded`, `aria-controls`) are essential for a robust and accessible user experience.
**Action:** Always prefer semantic HTML elements for interactive components and ensure their state is programmatically communicated to assistive technologies.
